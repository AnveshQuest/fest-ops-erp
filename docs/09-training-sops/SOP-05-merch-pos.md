# SOP-05 · Sell merchandise and close the day

**Who:** Merch counter volunteers

### Start of shift
1. Open **Point of Sale**. If asked, create a **POS Opening Entry** with the cash in the box.

### Each sale (target: under 30 seconds)
1. Tap the items (T-shirt by size, hoodie, wristband). Change quantity if needed. `[screenshot]`
2. **Checkout** → choose **UPI** or **Cash** → enter amount received → **Complete Order**.
3. Show the buyer the screen; print only if asked.

### End of day
1. **Menu → Close the POS** (POS Closing Entry).
2. Count the cash; check UPI received on the merch account's phone.
3. Enter counted amounts. If there's a difference, write the reason in the remarks and tell the Merch Head.

### Never
- Sell without entering the sale.
- Give discounts unless the Merch Head has set them up.
